# Design reference provenance

`apple.DESIGN.md` is from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md), retrieved 10 October 2026. It is distributed under the included `VoltAgent-LICENSE` (MIT).

Used as inspiration: white and #f5f5f7 surfaces, #1d1d1f ink, #0066cc actions, 400/600 typography, rounded action controls, restrained motion and no shadows on interface chrome. The light navigation, Geist face, résumé reading order and accessible interaction states are project-specific decisions. The implemented system is documented in the root `DESIGN.md`.

The collection is a Markdown reference library, not an executable Codex plugin. UI UX Pro Max is separately installed as a Codex skill. No brand logos, proprietary fonts or Apple product claims are reproduced.
